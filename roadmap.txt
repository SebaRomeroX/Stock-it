PHASE 1 — SETUP  [DONE]  2026-10-10
--------------------------------------------------------------
What:
  - Project skeleton: index.html, css/styles.css, js/main.js
  - Mobile-first viewport + base styles, dark theme by default
  - roadmap.txt created (this file)

Decisions:
  - Stack: plain HTML + CSS + JS. Zero dependencies, no npm,
    no build step, no framework. Rationale: simplest possible
    toolchain, everything runs by opening index.html.
  - Modules: native ES modules (type="module"). Rationale:
    modularity without tooling. Requires serving over HTTP
    (e.g. `python3 -m http.server`) instead of file:// —
    accepted tradeoff.
  - Persistence: localStorage with JSON serialization.
    Rationale: zero deps, synchronous, enough for a small
    store. Escape hatch: switch storage.js to IndexedDB later
    without touching feature code (see storage contract below).
  - Theme: CSS custom properties, dark-first, light theme
    ready to add via [data-theme="light"].
  - Layout: single page, bottom navigation bar (thumb-reach),
    max-width container so it also looks OK on desktop.

Storage contract (storage.js):
  - load(key) -> parsed object or default
  - save(key, value) -> writes JSON
  - reset(key) -> removes key
  Feature modules never touch localStorage directly.

Next goal: Phase 2 — data layer (storage.js).
